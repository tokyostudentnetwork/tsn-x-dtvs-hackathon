# NextGen Hackacase
### A collaboration between *Tokyo Student Network* and *Deloitte Tohmatsu Venture Support*. 

This student-led hackathon is a two-day interdisciplinary challenge in which the problems are not just invented for the occasion, but present novel challenges for participants to solve. Deloitte Tohmatsu Venture Support will supply genuine operational and business problems. Please visit https://tokyostudentnetwork.github.io/tsn-x-dtvs-hackathon/ to learn more!
